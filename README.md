# Log

Log is a small, heavily vibecoded daily journalling app built to be fast.
I built this after getting tired of how long my Notion journal kept taking really long to load. 

It keeps daily entries in three simple buckets:
- food
- workout
- work

The app is built with SwiftUI and SwiftData. It includes:
- a Today screen for the current entry
- a History screen with list and calendar views
- a Search screen for finding past entries
- photo support for food entries
- CSV export for sharing or backup

The goal is simple: open the app, write quickly, and move on.
